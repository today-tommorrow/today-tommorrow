## 연동 계약

POST submit {expected_revision:N,review_token:<서버 발급>}+Idempotency-Key → 202. 미완료 422, stale/자료 미완료 409. run의 matches/unknown_conditions/empty/unsupported_field와 job.failed를 구분. G=1,P=null,O=.5,F=1일 때 lower=.65,upper=.90,coverage=.75이며 확률 표시 금지.

합성/공개 사용 허용 샘플만 사용한다. 예시는 필드 중심이며 전체 필수 필드·타입·HTTP 상태는 연결된 계약을 따른다. 성공/오류/빈 결과의 완전한 요청·응답 fixture를 구현 PR에 기록하고, 변경 전후 예시를 관련 영역과 확인한다.

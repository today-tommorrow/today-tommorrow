## 연동 계약

./setup → ./dev → ./check. 실제 GET /api/health 200 {"status":"ok"}; 본인 DB 장애 시 503 {"detail":"database_unavailable"}. Node/Python은 버전 파일 기준이며 setup만 필요한 런타임을 설치한다.

합성/공개 사용 허용 샘플만 사용한다. 예시는 필드 중심이며 전체 필수 필드·타입·HTTP 상태는 연결된 계약을 따른다. 성공/오류/빈 결과의 완전한 요청·응답 fixture를 구현 PR에 기록하고, 변경 전후 예시를 관련 영역과 확인한다.

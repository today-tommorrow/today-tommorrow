## 연동 계약

GET /api/courses/compare?ids=<id1>,<id2> → 계약의 상세 목록. 비교 개수 제한·중복/없는 ID 처리는 OpenAPI와 D13 확정 예시를 적용한다. 정적 /compare 라우트가 /{course_id}에 가려지지 않도록 검증.

합성/공개 사용 허용 샘플만 사용한다. 예시는 필드 중심이며 전체 필수 필드·타입·HTTP 상태는 연결된 계약을 따른다. 성공/오류/빈 결과의 완전한 요청·응답 fixture를 구현 PR에 기록하고, 변경 전후 예시를 관련 영역과 확인한다.

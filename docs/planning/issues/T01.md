## 연동 계약

문서 시작점은 docs/README.md. HTTP 경로는 OpenAPI servers=/api + paths. 질문 생성은 expected_revision, 답변은 expected_revision + selected_option_id만 전송. YAML/JSON/TS와 모델 계약을 같은 샘플로 비교한다.

합성/공개 사용 허용 샘플만 사용한다. 예시는 필드 중심이며 전체 필수 필드·타입·HTTP 상태는 연결된 계약을 따른다. 성공/오류/빈 결과의 완전한 요청·응답 fixture를 구현 PR에 기록하고, 변경 전후 예시를 관련 영역과 확인한다.

## 연동 계약

PR에서 TS/ESLint/Prettier/Vitest/Ruff/API·scripts unittest/Vite build 수행. Node/Python은 버전 파일을 사용. Linux runner에는 정확한 Node/npm을 먼저 준비해 macOS 캐시 다운로드에 의존하지 않는다.

합성/공개 사용 허용 샘플만 사용한다. 예시는 필드 중심이며 전체 필수 필드·타입·HTTP 상태는 연결된 계약을 따른다. 성공/오류/빈 결과의 완전한 요청·응답 fixture를 구현 PR에 기록하고, 변경 전후 예시를 관련 영역과 확인한다.

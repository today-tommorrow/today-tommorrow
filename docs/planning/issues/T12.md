## 연동 계약

POST /api/profiles/{id}/documents/files multipart expected_revision/kind/file → 202 DocumentAccepted; texts는 expected_revision/kind/text. 옵션 API의 한도 준수. 크기 초과 413, 미지원 형식 415, 처리 실패는 Document.failed.

합성/공개 사용 허용 샘플만 사용한다. 예시는 필드 중심이며 전체 필수 필드·타입·HTTP 상태는 연결된 계약을 따른다. 성공/오류/빈 결과의 완전한 요청·응답 fixture를 구현 PR에 기록하고, 변경 전후 예시를 관련 영역과 확인한다.

## 연동 계약

POST documents/links {expected_revision:3,kind:"job_description",url:<공개 합성 테스트 URL>} → 202. DNS·실제 연결 IP·redirect/재시도마다 사설/loopback/link-local/metadata 차단. 차단·timeout은 실패 자료로 표시.

합성/공개 사용 허용 샘플만 사용한다. 예시는 필드 중심이며 전체 필수 필드·타입·HTTP 상태는 연결된 계약을 따른다. 성공/오류/빈 결과의 완전한 요청·응답 fixture를 구현 PR에 기록하고, 변경 전후 예시를 관련 영역과 확인한다.

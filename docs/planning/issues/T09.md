## 연동 계약

POST questions {expected_revision:0}+Idempotency-Key → 202 JobAccepted 또는 200 IntakeState. GET question → public IntakeQuestion. POST answer {expected_revision:0,selected_option_id:<반환 UUID>} → 200 Profile revision=1. 서버 저장 patch만 적용.

합성/공개 사용 허용 샘플만 사용한다. 예시는 필드 중심이며 전체 필수 필드·타입·HTTP 상태는 연결된 계약을 따른다. 성공/오류/빈 결과의 완전한 요청·응답 fixture를 구현 PR에 기록하고, 변경 전후 예시를 관련 영역과 확인한다.

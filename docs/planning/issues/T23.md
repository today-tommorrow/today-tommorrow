## 연동 계약

PUT /api/me/saved-courses/{course_id} → 204; GET /api/me/saved-courses → CoursePage; DELETE → 204. 같은 과정 반복 저장의 멱등성과 catalog_version 전환 시 정책을 D10으로 확정.

합성/공개 사용 허용 샘플만 사용한다. 예시는 필드 중심이며 전체 필수 필드·타입·HTTP 상태는 연결된 계약을 따른다. 성공/오류/빈 결과의 완전한 요청·응답 fixture를 구현 PR에 기록하고, 변경 전후 예시를 관련 영역과 확인한다.

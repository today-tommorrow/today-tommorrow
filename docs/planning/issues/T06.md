## 연동 계약

POST /api/profiles → 201 Profile. PATCH /api/profiles/{id} {expected_revision:0,answers:{entry_intent:"explore"}} → 200 revision=1. 오래된 revision은 409. 재로그인 시 현재 초안을 찾는 방식은 D06에서 확정한다.

합성/공개 사용 허용 샘플만 사용한다. 예시는 필드 중심이며 전체 필수 필드·타입·HTTP 상태는 연결된 계약을 따른다. 성공/오류/빈 결과의 완전한 요청·응답 fixture를 구현 PR에 기록하고, 변경 전후 예시를 관련 영역과 확인한다.

## 연동 계약

POST interpretations {expected_revision:2,text:"주말에 온라인으로 배우고 싶어요",ready_document_ids:[]} → 202. apply의 accepted/rejected ID는 모든 제안을 서로소로 분할. revision/hash 불일치 409, 빈 text와 빈 자료 모두 422.

합성/공개 사용 허용 샘플만 사용한다. 예시는 필드 중심이며 전체 필수 필드·타입·HTTP 상태는 연결된 계약을 따른다. 성공/오류/빈 결과의 완전한 요청·응답 fixture를 구현 PR에 기록하고, 변경 전후 예시를 관련 영역과 확인한다.

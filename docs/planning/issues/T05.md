## 연동 계약

GET /api/auth/google/start → 302; callback 성공 → /onboarding, 취소 → /login?error=oauth_cancelled. GET /api/auth/me → AuthSession; POST logout → 204. 비로그인 개인 API는 401, CSRF 불일치는 403.

합성/공개 사용 허용 샘플만 사용한다. 예시는 필드 중심이며 전체 필수 필드·타입·HTTP 상태는 연결된 계약을 따른다. 성공/오류/빈 결과의 완전한 요청·응답 fixture를 구현 PR에 기록하고, 변경 전후 예시를 관련 영역과 확인한다.

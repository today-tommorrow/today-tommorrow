## v0.8 · 선택으로 시작하는 맞춤 질문

**Google 로그인 → Gemma가 만든 질문·선택지에 응답 → 필요한 자료 확인 → 전체 확인·제출 → 교육 추천.**<br>첫 화면은 선택 카드로 시작한다. 기존 화면 구성은 유지하고 질문 내용과 선택지 후보를 local Gemma가 사용자 맥락에 맞춰 생성한다.

| 구분 | 확정 사항과 구현 제안 |
| --- | --- |
| 이번 사용자 확정 | 초기 글쓰기 요구 제거. 지금의 질문·선택 카드·버튼 UI 유지. local Gemma가 질문과 선택지 후보를 구조화된 출력으로 생성. |

## 기존 UI에서 질문과 선택지만 맞춤 생성

| 시점 | 사용자가 보는 화면 | Gemma / 서버 동작 |
| --- | --- | --- |
| 첫 진입 | “지금 어떤 마음으로 배움을 찾고 있나요?”와 선택 카드. 처음부터 빈 글쓰기 칸을 보여주거나 글을 요구하지 않는다. | 서버가 첫 입력의 허용 슬롯·선택형 시작 지침을 전달하고 local Gemma가 첫 질문·후보를 생성한다. |
| 선택 직후 | 선택한 내용이 요약 칩에 남고, 그 답변에 연결되는 다음 질문이 나온다. | 서버가 선택을 먼저 확정하고 revision을 올린다. 그 최신 문맥으로 다음 질문을 생성한다. |
| 데이터 분석·기초 경험 선택 | 예: “예제를 따라 해본 다음, 무엇을 더 해보고 싶나요?” / 다른 데이터에 적용·원리 이해·협업 경험. | 공통 질문을 그대로 읽는 대신 분야·경험에 맞는 질문과 의미 있는 선택지 후보를 생성한다. |
| 웹 서비스·개인 프로젝트 선택 | 예: “직접 만든 서비스에서 다음에 무엇을 더 해보고 싶나요?” / 새 기능·구조 개선·팀 개발. | 앞선 선택이 다르면 질문뿐 아니라 선택지의 구체적 내용도 달라진다. 예시는 시연 문구이며 고정 질문은행 계약이 아니다. |
| 원하는 답이 선택지에 없음 | 기존 화면 아래의 “직접 알려줄게요” 보조 경로를 사용한다. | 자유문장 해석 API로 제안 생성 → 사용자 확인. 필수 글쓰기로 전환하지 않는다. |
| 자료 있음 | 파일·링크·직접 붙여넣기 화면을 유지한다. 추출한 정보는 확인 후 입력에 반영한다. | ready 자료의 확인된 근거만 다음 질문에 사용. 미확인 문서 사실을 사용자 경험으로 단정하지 않는다. |
| 미정 / 온라인 / 초보 | 미정은 반복 질문하지 않음. 온라인만 원하면 통학 지역 생략. 초보에게 과거 학습의 아쉬움을 강제하지 않음. | 서버 슬롯 상태와 의존성으로 불필요한 질문을 제외한다. |
| 전체 입력 완료 | 지금까지 선택한 구체적 문구·자료·미정 항목을 한 화면에서 확인한다. | 완료·review_token은 서버 판정. Gemma가 done을 출력해 임의 종료하지 않는다. |

핵심은 **정해진 선택형 UI에 LLM이 생성한 질문·선택지를 표시**하는 것이다. 질문을 생성하는 단계와 사용자에게 교육을 추천하는 단계는 분리한다. 입력 도중 교육 카드·교육명·추천 링크는 반환하지 않는다.

### 수집 범위와 질문 선택

| 영역 | 처리할 정보 |
| --- | --- |
| 방향 | 출발 상황·관심 직무/주제·활동. 미정은 undecided로 완료 가능. |
| 경험 | 현재 경험·보완할 점·자료 있음/없음. 경험 미정과 처음 시작을 구분. |
| 학습 목표 | 기초·구체적인 결과물·협업 등 원하는 결과. 사용자가 선택한 문구도 보존. |
| 참여 조건 | 시간·방식·필요한 통학 범위·예산·시기. 정하지 않은 값은 unknown. |
| 완료 | 모든 적용 항목을 확정/명시적 미정/없음/N/A로 처리하고 자료 확인·상충 해소. 입력량은 사용자 맥락에 따라 달라진다. |

서버는 미완료·상충 슬롯 중 의존관계를 충족하는 eligible_slots를 만들고, Gemma는 그 범위에서 다음 질문의 target_slot과 선택지 내용을 구성한다. 완료된 항목을 재질문할 수 있는 경우는 사용자가 직접 수정했거나 해당 답변의 근거가 변경된 경우다. 문서에서 이미 확인한 항목은 건너뛴다. 동일한 의미의 질문을 표현만 바꾸어 반복하지 않도록 target·intent·확정 상태를 함께 비교한다.
